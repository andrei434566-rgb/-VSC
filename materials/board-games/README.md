# Настольные игры — 10 класс

Материалы для пяти команд: геология, бурение, геонавигация, обустройство и разработка.

Презентация: «Настольные игры — правила для команд», 6 слайдов. На каждом командном слайде: задание, материалы и программы, основные правила, критерии оценивания (25 баллов), проверка готовности.

Файлы PowerPoint и Word подготовлены для распространения учащимся и учителям. Для загрузки бинарных файлов используйте GitHub Releases (релиз v1.0.0) или GitHub Upload files: текущая интеграция GitHub не поддерживает добавление бинарных вложений в релиз.
