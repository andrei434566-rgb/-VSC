# АгентVSC

**АгентVSC** — комплект инструкций и команд для работы с Git-репозиториями из VS Code. По запросу он может клонировать репозиторий в выбранную папку или обновить уже существующую локальную копию из `origin`.

Подходит для разных репозиториев, а не привязан к одному проекту. Для приватных репозиториев у пользователя должны быть настроены доступ и Git-учётные данные на компьютере.

## Установка

1. Распакуйте архив `AgentVSC-v1.0.0.zip`.
2. Откройте папку `AgentVSC` в VS Code. Чтобы агент видел другой проект, можно добавить обе папки в одно многоцелевое рабочее пространство VS Code.
3. При запросе VS Code доверьте папку, если хотите разрешить запуск локальных команд.
4. Попросите ИИ-агента, например: «Склонируй https://github.com/owner/repository в `C:\Projects\repository`» или «Обнови `C:\Projects\repository` из GitHub».

## Запуск команды вручную

Откройте `Ctrl+Shift+P` → **Tasks: Run Task** и выберите **AgentVSC: Clone or update repository**. Укажите URL или SSH-адрес репозитория либо путь к уже существующей локальной копии. При клонировании укажите папку назначения.

## Правила обновления

- Для клонирования папка назначения должна отсутствовать или быть пустой.
- Для обновления целевая папка должна быть корнем Git-репозитория с настроенным `origin` и выбранной веткой.
- Обновление разрешено только при чистой рабочей копии и выполняется как `git pull --ff-only` текущей ветки.
- При локальных изменениях, неверном пути или невозможности fast-forward команда останавливается и показывает причину.
- Скрипт никогда не выполняет `stash`, `reset`, `clean`, `commit` или `push`.

ИИ-модель не включена в этот архив: используются расширения и агент, уже установленные в VS Code.
