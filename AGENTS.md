# Инструкции для АгентVSC

Используй эти инструкции только когда пользователь явно просит получить или обновить репозиторий из удалённого Git-источника.

- Если пользователь передал URL/SSH-адрес репозитория, клонируй его в указанную папку командой `.vscode/sync_repository.ps1 -Repository <url> -DestinationPath <путь>`.
- Если пользователь указал путь к уже существующему локальному репозиторию, обнови его командой `.vscode/sync_repository.ps1 -Repository <путь>`.
- Если для клонирования не указан адрес или путь назначения, уточни недостающие данные до запуска команды.
- После успешного клонирования открой целевую папку в текущем окне VS Code или добавь её в рабочее пространство, чтобы пользователь мог редактировать код и видеть структуру.
- После успешного обновления сообщи активную ветку и результат Git-команды.
- Если скрипт остановился из-за локальных изменений или ошибки Git, объясни вывод и не обходи защиту.

Не запускай синхронизацию при обычных запросах на редактирование кода. Никогда не выполняй `stash`, `reset`, `clean`, `commit` или `push` как часть клонирования/обновления. Не меняй remotes или ветки пользователя.
